# FacultyProject-CHS
HSC (ro. CHS) project - Year 4, Sem 1

This is a faculty project for the Hardware-Software Codesign (en. HSC, ro. CHS) course at Politehnica University of Timișoara.
This project is designed and intended to be completed by two students, those being the owners of this repo (SovietskySoldatie & Levy4545).

Chosen project theme: Smart Alarm Clock, disabled by scanning custom configured items
